# Machine Learning Modelling Process
A Python implementation demonstrating the basic Machine Learning modelling workflow, including dataset loading, data splitting, and model training.

## Technologies Used
* Python
* Scikit-learn
* Pandas
* NumPy
* Google Colab

## Workflow
1. Dataset Loading
2. Data Preparation
3. Splitting the Dataset
4. Model Training

## Dataset
Boston House Prices Dataset.

## Purpose
This repository demonstrates the basic workflow involved in preparing data and training a Machine Learning model using Scikit-learn.
